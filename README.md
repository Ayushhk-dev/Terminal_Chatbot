# 🤖 AI Chatbot

A simple command-line AI chatbot built with Python and the OpenAI API. Chat with an AI assistant directly from your terminal.

The project uses **GPT-6 Luna** to generate responses and demonstrates API integration, user input handling, loops, and exception handling in Python.

## ✨ Features

- 💬 Interactive terminal-based conversations
- 🧠 AI-generated responses using GPT-6 Luna
- ⚙️ Configurable assistant instructions
- 🔄 Continuous conversation loop
- 🛡️ Basic error handling
- 🔐 API key loaded from an environment variable
- 🚪 Simple exit command

## 🛠️ Built With

- **Python** — application logic
- **OpenAI Python SDK** — API integration
- **OpenAI Responses API** — AI-generated responses
- **GPT-6 Luna** — language model (`gpt-6-luna`)

## 📋 Requirements

- Python 3.10 or newer
- An OpenAI API account
- An API key with access to the selected model
- Internet connection

> **Note:** OpenAI API usage is billed separately from a ChatGPT subscription. Check your API account's billing and usage limits before running the chatbot.

## 🚀 Getting Started

### 1. Clone the repository

Make sure Git is installed, then run:

```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/YOUR-REPOSITORY.git
```

Navigate into the downloaded project:

```bash
cd YOUR-REPOSITORY
```

Replace the example repository URL and directory name with your actual GitHub repository details.

### 2. Create a virtual environment

**Windows (PowerShell):**

```powershell
python -m venv .venv
```

Activate it:

```powershell
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

Install the OpenAI Python SDK:

```bash
python -m pip install openai
```

### 4. Get an OpenAI API key

1. Visit the [OpenAI API Keys page](https://platform.openai.com/api-keys).
2. Sign in to your OpenAI API account.
3. Create a new secret API key.
4. Copy the key when it is displayed and store it securely.

**Important:** A secret API key is sensitive. Never publish it in your code, README, screenshots, or public GitHub repository.

### 5. Configure your API key

The chatbot reads its API key from the `OPENAI_API_KEY` environment variable.

**Windows (PowerShell):**

```powershell
$env:OPENAI_API_KEY = "your-api-key-here"
```

**macOS / Linux:**

```bash
export OPENAI_API_KEY="your-api-key-here"
```

Replace `your-api-key-here` with your actual secret key.

These commands configure the variable for the current terminal session. If you open a new terminal, set it again.

### 6. Run the chatbot

With the virtual environment activated and the API key configured, run:

```bash
python gpt_6.0_luna.py
```

The chatbot should start in your terminal and prompt you to enter a message.

## ⚙️ Configuration

The model and assistant instructions can be customized in `gpt_6.0_luna.py`.

**Model:**

```python
MODEL = "gpt-6-luna"
```

**Assistant instructions:**

```python
INSTRUCTIONS = """
You are a helpful AI assistant.
Give clear, accurate answers.
If you are unsure about something, say so.
"""
```

You can change the instructions to customize the chatbot's behavior. The model ID must be available to your API account.

## 🔒 Security

- Never hardcode your API key in `gpt_6.0_luna.py`.
- Never commit API keys or other secrets to GitHub.
- Keep `.venv/` and local secret files out of version control.
- Monitor your API usage and configure appropriate spending limits where available.
- If a key is exposed, revoke it and create a replacement.

For more information, see the [OpenAI API key safety guide](https://help.openai.com/en/articles/5112595-best-practices-for-api-key-safety).
